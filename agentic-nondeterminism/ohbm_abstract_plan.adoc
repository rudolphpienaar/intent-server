== Goal
Prepare an OHBM 2026 abstract (theory/simulation only) about failure modes of agentic orchestration in neuroimaging pipelines (FreeSurfer-style workflows on ChRIS) and the bounding effect of an Intent-Action Server (IAS). This note defines the math model, metrics, and planned figures for a quick Python simulation that will feed the abstract.

== Model assumptions
* Pipeline depth: N levels of orchestration (API/CLI calls may branch).
* Branching factor: b controls fan-out; effective calls = geometric series, not just N.
* Per-step error (unbounded agent): p.
* Per-step error (IAS-bounded): p' < p, reflecting constrained actions and validated params.
* Correlated cascades: c in [0, 1] increases effective error with depth to capture parameter drift/tool mismatch (c = 0 reduces to independent errors).
* Misreport rate: r = probability the agent reports success despite an underlying failure.
* Human-in-loop intent check: reduces r and p' for IAS scenario by enforcing structured outputs and schema validation.

== Core equations
* Effective calls with branching b: N_eff = ((b^N) - 1) / (b - 1) for b > 1; else N.
* Independent failure probability: F_ind = 1 - (1 - p)^(N_eff).
* Correlated failure probability (simple linear cascade term): F_corr = 1 - (1 - p)^(N_eff) * (1 + c * (N_eff - 1)).  (Clip to [0, 1].)
* Misreport probability: M = F * r, where F is either F_ind or F_corr.
* IAS-bounded versions swap p → p', c → c', r → r', with p' << p and r' << r.

== Metrics to report
* Failure probability vs. pipeline depth N (log-scaled) at fixed p, p', c, c', b, b'.
* Sensitivity of failure to per-step error p at fixed N.
* Misreport probability vs. N (with/without IAS).
* “Safe region” threshold: smallest N such that F <= α (e.g., α = 0.05) for given p; compare unbounded vs. IAS-bounded.
